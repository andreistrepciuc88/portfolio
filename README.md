## Il progetto

Un sito statico, responsive e in italiano, costruito con HTML, CSS e JavaScript puri: **nessun framework, nessun database, nessun build step**. Raccoglie chi sono, le mie passioni e i progetti su cui lavoro.

## Cosa contiene

- **Hero, Chi sono, Passioni, Progetti e Contatti** in una sola pagina, con navigazione fluida e menu per mobile
- **Informativa privacy** con legenda dei punti che segue lo scroll
- **Neon Ride**, un minigioco arcade su `canvas`: guida la moto, schiva le auto e batti il tuo record. Comandi con le frecce o `A` / `D`, tasti a schermo su telefono. Il record resta solo nel tuo browser

## Scelte di progetto

- **Zero tracciamento:** niente cookie, analytics o pubblicità
- **Nessuna dipendenza esterna:** font e immagini sono locali, senza richieste a servizi di terzi
- **Accessibilità:** HTML semantico, navigazione da tastiera, rispetto di `prefers-reduced-motion`

## Struttura

```text
.
├── index.html          # Pagina principale
├── privacy.html        # Informativa sulla privacy
├── styles.css          # Stile del sito
├── script.js           # Menu mobile e minigioco

```

## Tecnologie

- **HTML5** semantico
- **CSS3:** variabili, grid, flexbox, `clamp()` e media query
- **JavaScript** senza librerie
- **Font:** DM Sans e Space Grotesk
